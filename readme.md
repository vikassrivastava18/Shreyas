# Shreyas

Shreyas is an educational platform focused primarily on computer science topics. The project aims to combine curated learning content, interactive tutoring, quizzes, and coding exercises into a single learning experience.

## Overview

The application will gather learning material from open-source books, tutorials, and other high-quality educational resources. It will present each topic in a structured way, including:

- Concept summaries (text and video)
- AI-assisted explanations and doubt clearing
- Practice quizzes
- Coding problems at multiple difficulty levels
- Optional guided hand-holding for beginners

## Goals

The platform is designed to help students learn by doing, not just by reading. The experience will encourage active learning through explanations, problem solving, and iterative feedback.

## Features

- Large knowledge base across subjects such as Python, SQL, JavaScript, Machine Learning, Microcontrollers, and IoT
- Topic-wise summaries and structured study material
- Interactive chat-based tutoring to answer learner questions
- Quizzes to reinforce understanding
- Coding challenges grouped into easy, intermediate, and hard levels
- Support for guided learning flows before independent problem solving
- AI-generated content where needed to fill gaps in educational material

## Tech Stack

- Frontend: Vue
- Backend: Django
- Database: PostgreSQL
- Agentic chat: LangGraph
- Testing: Unit and integration testing with strong coverage

## Roadmap

### Phase 1: Content Foundation
- Gather and organize learning material from trusted open-source sources
- Build a large knowledge base for key CS subjects

### Phase 2: Learning Experience
- Create summary pages for each topic
- Add quizzes and concept checks
- Add coding problems across difficulty levels

### Phase 3: AI Learning Support
- Implement agentic chat for explanatory support and doubt resolution
- Add quizzes and coding functionality

### Phase 4: Validation and Quality
- Improve application reliability through unit and integration tests
- Ensure strong coverage across critical features

## Project Status

This project is in early development and is being built as a comprehensive CS learning platform.
